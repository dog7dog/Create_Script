## 7. 予想と異なった GitHub の動作 [GitHub]

1. **インストールの前に秘密鍵が必要だった。** 画面に「You must generate a private key in order to install your GitHub App.」と表示された。読んだ文書の範囲には、この記載が無かった。
2. **「Only on this account」の App は、認証なしの `GET /apps/<slug>` で 404 になる。** App の権限は、JWT の `GET /app` で確かめた。
3. **`updated_at` は `created_at` より少し後になる**（A で 0.19 秒、C で 0.017 秒）。作成の直後に内部で更新されると考えられる。
4. **履歴（`…/history`）の版の時刻は、本体の `updated_at` と一致しない**（0.1〜0.19 秒のずれ）。そのため、照合には使わない。
5. **時刻の表記がトークンの主体で違う。** 所有者は `+09:00`、App と `GITHUB_TOKEN` は `Z`。そのため、時刻として比較している。
6. **ruleset の違反のエラーの文言が、API によって違う。** `POST git/refs` は 422「Reference update failed」だけで、理由は rule suite で分かった。`PATCH`・`DELETE git/refs` は 422 で、本文に「Repository rule violations found …」があった。git push は GH013。
7. **rule suite の記録のされ方。** rule suite の `actor_id` は、Publisher App の bot ユーザーの ID（356075009）で、App ID ではない。git push の経路では `secret_scanning` も評価される。ruleset に当たらない操作（`pt-control`）は記録されない。
8. **job summary は REST API で取得できなかった**（6.1）。

   - admin は ruleset を変更・無効化・削除できる。案 B' はそれを検知して止めるだけで、防げない。
